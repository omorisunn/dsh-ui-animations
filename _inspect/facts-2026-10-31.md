## C. keyframes 全量与入场先例

全量 14 个：spin、dsh-state-dot-spin、dsh-state-dot-dash、dsh-row-shimmer-sweep、dsh-row-shimmer-highlight、modalEnter、indicator-enter、reveal-second-dot、reveal-third-dot、tooltip-in、dsh-toast-in、dsh-toast-fade、dockHintIn、dockScrimIn。

- modalEnter（纯 opacity 0→1）：o6lrb `_mask_o6lrb_18:after` 与 `_dialog_o6lrb_33` 均 `animation:_modalEnter_o6lrb_1 var(--ds-transition-duration) var(--ds-ease-in-out)`，reduced-motion `animation:none`。→ 库内「modal 进场=0.2s 淡入」语言，设置面板未用它。
- dockHintIn：`0%{opacity:0;transform:scale(.98)} to{opacity:1;transform:none}` .14s ease-out → **opacity+收敛 scale 的进场先例**（提案 scale 依据）。
- hover preview 卡（38jqx，进+退纯 CSS 标准式，asar/CSS 双证）：`transition:opacity var(--dsh-hover-preview-fade) linear` + `@starting-style{opacity:0}` + `[data-closing]{opacity:0;pointer-events:none}` + reduced-motion `transition:none`；JS 设 data-closing 后再卸载（web bundle 中 data-closing 唯一使用点）→ 提案的机制母本。

## D. 出场（全库缺口）

- 唯一出场动画 = toast：`._toast_l6cvn_6{animation:_dsh-toast-in_l6cvn_1 .16s ease-out,_dsh-toast-fade_l6cvn_1 1s ease var(--dsh-toast-hold,3s) forwards}`，`dsh-toast-fade{to{opacity:0;visibility:hidden}}`——元件**常驻不卸载**，靠 forwards+visibility 收尾。常驻前提不适用于 React 卸载模型的面板。
- dialog/mask/dock/设置面板均无出场动画，关闭即瞬跳。
- JS `animationend` 仅 4 处且全为库内部（React polyfill、darwin transition 追踪），无 UI 组件用它协调卸载 → 「播完再卸载」机制需新建（=Phase 2 上游 closing 态）。

## E. reduced-motion 现状

有分支：o6lrb modalEnter（animation:none）、spinner/shimmer 装饰、38jqx（transition:none）。
欠账（存量，不动只记）：toast、dockScrim、dockHint、tooltip、indicator 无分支。

## F. 高频面与插件机制

- 5 处 transition:none（高频面）保持原样，本轮不触及。
- 插件 CSS 机制：`window.__ModuleLoader__.load({id,factory})`，factory 内联 css 字符串 → `<style data-plugin data-plugin-css=…>` 注入 document.head（按 tagId 去重，文档序可覆盖）。动效插件按此投放 CSS，无需改上游。
- `data-shortcut-modal` 值：settings（settings-general）、shortcut-edit（shortcuts 包）→ 面板家族扩展锚点。
- 类名 hash（AnXs9G 等）为构建产物，随版本可能变；稳定选择器=`[data-shortcut-modal="settings"]` + :has() 结构式。
